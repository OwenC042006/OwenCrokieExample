# C++ Order Management System

**CS 2401 — Spring 2026 | 3-Person Team Project**

A command-line order management application developed in C++ using object-oriented programming, inheritance, polymorphism, STL containers, dynamic memory, and file persistence.

## What It Does

The application allows users to:

* Create customer orders
* Add different types of products to orders
* View and remove orders
* Calculate order totals
* Save orders to a file
* Load previously saved orders when the program starts

Products are managed through a shared abstract interface, allowing different product types to be handled through the same order system.

## Technical Highlights

* **C++ OOP:** Abstract classes, inheritance, virtual functions, and polymorphism
* **Memory Management:** Dynamic allocation, destructors, copy constructors, and deep copying
* **Data Structures:** STL `list` and iterators
* **Persistence:** File I/O and reconstruction of saved objects
* **Design:** Polymorphic `clone()` system for safely copying different product types

## Team Development

Completed as a **three-person team project**. Development involved dividing responsibilities, working with Git branches, merging individual contributions, and integrating components into a single application.
